- **1400-1412**：profile 和 NTP 字段合法；不写系统时间可避免权限要求。
- **1414-1420**：TUN 字段合法；`auto-redirect` 仅 Linux 生效，其他平台会忽略/不利用该能力。
- **1421（已由用户确认按需保留）**：`172.168/16` 虽不是 RFC1918 私网，但用户明确要求该公网段绕过代理，因此不修改。
- **1424-1432**：节点、组和 provider 汇总完整，但无条件追加 `directProxies` 放大了前述跨来源重名问题。
- **1434-1445**：规则顺序为前置直连 → QUIC → 广告/服务 → 国内外兜底 → MATCH，整体正确。
- **1447**：返回新对象，不污染输入顶层配置，合理。
